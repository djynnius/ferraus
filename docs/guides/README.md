# ferraus

ferraus is one cross-platform binary that gives people and AI agents a complete
music-editing toolkit from the command line: conversion and editing, effects, Audition-class
restoration, noise reduction, stem separation, pitch correction, MIDI, notation in both
directions, CLAP/VST3 instrument hosting, and mastering.

* New here? Start with [Getting started](getting-started.md), then a tutorial.
* Building an agent? Read the [agent guide](agents.md) and [MCP setup](concepts/mcp.md).
* Looking up a command? Every command has a reference page under *Command reference*, and
  `ferraus docs <command>` prints the same page offline.

Every page is generated from the same command definitions as the binary, and every example
runs in CI.
